## 1. 共通レイアウト（サイドナビゲーション）

全画面で共通して左側に表示されるメインナビゲーションメニューです。

### 構成要素

| No | 項目名 | 種別 | 説明 / 遷移先 |

| :-- | :--------------- | :------- | :------------------------------------- |

| 1 | ロゴ（学習管理） | ロゴ | トップページ（ダッシュボード）へ遷移 |

| 2 | ダッシュボード | メニュー | 「ダッシュボード」画面へ遷移 |

| 3 | タスク一覧 | メニュー | 「タスク一覧」画面へ遷移 |

## 2. ダッシュボード画面

学習の進捗状況や現在のステータスをグラフや数値で可視化し、一目で把握するための画面です。

### 2.1 画面上部：サマリーカード

- **今週の学習時間**: 今週の合計学習時間。先週比（増減時間）を併記。

- **進捗率**: 全タスクのうち完了したタスクの割合（完了数 / 全体数）を％表示。

- **完了タスク**: 今週完了したタスク件数（完了数 / 全体数）。

- **読了書籍**: 読了した書籍の冊数（読了数 / 全登録冊数）。

### 2.2 画面中部：学習時間グラフ

- **日別学習時間**: 曜日ごと（月〜日）の学習時間を表す棒グラフ（単位：時間）。

- **カテゴリ別学習時間**: 技術要素やカテゴリごとの学習時間を表すグラフ。

### 2.3 画面下部：進捗状況

- **ステータス別件数**: 未着手・進行中・完了のタスク数を表すグラフ。

- **書籍別進捗率**: 登録書籍ごとの進捗度を％で表す横棒グラフ。

- **カテゴリ別進捗率**: カテゴリごとの進捗度を表すグラフ。

- **進捗率推移**: 日別の予定進捗（％）と実績進捗（％）を比較する折れ線グラフ。

## 3. タスク一覧画面

登録された学習タスクを複数のビュー（カンバン、テーブル、カレンダー、タイムライン）に切り替えて管理する画面です。画面右上には「親タスク追加」ボタンが配置されています。

### 3.1 カンバン表示

- **未着手 / 進行中 / 完了** の 3 カラムでタスクカードをドラッグ＆ドロップ等で管理。

- タスクカードには「カテゴリタグ」「タスク名」「期日」「予定時間」「ステップ達成度」を表示。

### 3.2 テーブル表示

親タスクをアコーディオン形式で展開し、含まれる子タスク（章単位など）を一覧表示します。

| カラム名 | 種別 | 説明 |

| :--------- | :--------- | :------------------------------------------- |

| タイトル | テキスト | タスクの名称。親タスクはクリックで展開可能 |

| 種別 | タグ | 「本」「YouTube」などのタスク種別ラベル |

| ステータス | ステータス | 未着手 / 進行中 / 完了 のステータスを表示 |

| 予定日 | 日付 | タスクの予定日（締切日） |

| 完了日 | 日付 | 実際にタスクが完了した日付 |

| 学習時間 | 数値 | 実績学習時間（h） |

| ステップ | 分数 | 達成したステップ数 / 全ステップ数（例：2/4） |

| 操作 | ボタン | 「編集」ボタンからタスク詳細ダイアログを開く |

### 3.3 カレンダー表示

- 月表示のカレンダー形式。各日付に割り当てられたタスクを期間に応じたバー形式で配置。

- バー内には「カテゴリタグ」「タスク名」「ステップ達成度」を表示。

### 3.4 タイムライン（ガントチャート）表示

- 左側に親タスク名、右側に日付軸（1 日〜30 日）を配置したガントチャート。

- タスクの期間（開始予定日〜終了予定日）をタイムライン上のバーで可視化。

## 4. ダイアログ（モーダル画面）

### 4.1 親タスク登録ダイアログ

「親タスク追加」ボタン押下時に表示される簡易モダールです。

| 項目名 | 種別 | 入力ルール / 説明 |

| :----------------------- | :------------- | :--------------------------- |

| タイトル | テキスト | 必須入力。親タスクの名称 |

| メモ | テキストエリア | 任意入力。タスクの詳細やメモ |

| 削除 / キャンセル / 保存 | ボタン | 各種アクション実行ボタン |

### 4.2 タスク詳細・編集ダイアログ

タスクの新規登録、および既存タスクの編集・進捗更新を行うメインダイアログです。

| 項目名 | 種別 | 入力ルール / 説明 |

| :-------------------------------- | :--------------- | :---------------------------------------------------------- |

| タイトル | テキスト | 必須入力。タスクの名称（例：Chapter2 基本的なシンタックス） |

| 種別 | セレクトボックス | 「設定」画面で管理されているタスク種別から選択 |

| ステータス | セレクトボックス | 未着手 / 進行中 / 完了 |

| カテゴリ | セレクトボックス | 技術要素（TypeScript など）を選択 |

| 粒度 | セレクトボックス | タスクの細かさ（章単位など）を選択 |

| 紐づく書籍 | セレクトボックス | 「書籍マスタ」に登録されている書籍タイトルから選択 |

| 開始予定日 / 終了予定日 | 日付選択 | タスクの予定期間を設定（YYYY/MM/DD） |

| 開始日（実績） / 終了日（実績） | 日付選択 | 実際の着手日および完了日を入力 |

| 予定学習時間（h） / 学習時間（h） | 数値 | 予定時間と実績時間を半角数字で入力 |

| メモ | テキストエリア | 自由記述用の詳細メモ欄 |

| **ステップ** | エリア | 各章の中の細かいタスク（005 環境構築など）を管理するエリア |

| └ チェックボックス | チェック | 完了したステップにチェック。全体の進捗率に連動 |

| └ 新しいステップ | テキスト | 追加したいステップ名を入力するフォーム |

| └ 「追加」ボタン | ボタン | 入力したステップをリストに追加 |

| └ 「×」ボタン | ボタン | 各ステップの右側に配置。クリックでステップを削除 |

| **アクションボタン** | ボタン | 左下：「削除」 / 右下：「キャンセル」「保存」 |

## 5. 書籍マスタ画面

学習に使用する書籍を登録・管理し、進捗状況を一元管理する画面です。

### 5.1 画面上部：検索・フィルターエリア

- **書籍を検索...**: キーワードを入力して「検索」ボタンで書籍を絞り込み。

- **登録済みの書籍を絞り込む...**: 入力されたテキストに基づくリアルタイムフィルタリング。

### 5.2 画面中部：書籍カード一覧

登録された書籍がグリッド（カード形式）で一覧表示されます。

- **表示要素**: 書籍の表紙画像、書籍タイトル、著者名。

- **進捗バー**: 読了した章の割合をプログレスバーと「100% (8/8 章)」のようなテキストで可視化。

### 5.3 書籍詳細・編集ダイアログ

書籍カードをクリックした際に表示される、書籍情報の編集用モーダル画面です。

| 項目名 | 種別 | 入力ルール / 説明 |

| :----------------------- | :--------------- | :-------------------------------------------- |

| 書籍タイトル | ヘッダーテキスト | ダイアログの最上部に表示 |

| 著者名 | テキスト | 著者の氏名を表示・編集 |

| 全章数 | 数値 | 書籍のボリューム（総章数）を半角数字で入力 |

| メモ | テキストエリア | 書籍に関する備考やメモ |

| 削除 / キャンセル / 保存 | ボタン | 左下：「削除」 / 右下：「キャンセル」「保存」 |

## 6. 設定画面

アプリケーション内のマスタデータ（各種プルダウンの選択肢など）をカスタマイズする管理画面です。

### 6.1 タスク種別管理エリア

タスク登録ダイアログの「種別」セレクトボックスに表示されるマスタデータを動的に追加します。

| 項目名 | 種別 | 入力ルール / 説明 |

| :------------- | :------- | :----------------------------------------------------- |

| 新しい種別名 | テキスト | 新しく追加したい種別の名称を入力（例：動画、記事など） |

| 「追加」ボタン | ボタン | 入力した種別名を下のマスタリストに追加 |

### 6.2 タスク種別リスト（登録済み一覧）

現在登録されている種別が縦並びのリストで一覧表示されます（例：本、YouTube、自己開発、CyTech）。

| 各行の構成要素 | 種別 | 説明 |

| :------------- | :------- | :--------------------------------------------------------- |

| 種別名 | テキスト | 登録されている名称 |

| 「編集」ボタン | ボタン | 対象の種別名を入力可能状態（インプレース編集等）に切り替え |

| 「削除」ボタン | ボタン | 対象の種別をマスタから削除 |

## 2. ダッシュボード画面

学習の進捗状況や現在のステータスをグラフや数値で可視化し、一目で把握するための画面です。画面上部には期間切替トグル（週次 / 月次 / 年次 / 全期間）が配置され、選択された期間に応じて各カードやグラフの集計が動的に連動します。

### 2.1 画面上部：ヘッダー＆サマリーカード（4 枚）

画面最上部に**「今週の目標表示」エリア**を配置。その下部に 4 つの KPI サマリーカードを提示します。

| カード名           | 表示内容                                                                     | サブテキスト（前期間比較等）                                     |
| :----------------- | :--------------------------------------------------------------------------- | :--------------------------------------------------------------- |
| **期間の学習時間** | 選択された期間（週/月/年/全）の合計学習時間（時間単位・小数点 1 桁）         | 先週比 / 先月比 / 前年比 ±N 時間（全期間時は「全データの通算」） |
| **進捗率**         | 選択期間内のタスクを母数とした完了率（％）※下記「進捗率集計ロジック」参照    | 先週比 / 先月比 / 前年比 ±N％（全期間時は「全データの通算」）    |
| **進行中タスク**   | 選択期間内の「進行中」ステータスとなっているタスク件数                       | 完了 N / 全 N 件                                                 |
| **読了書籍**       | `completed_count >= total_chapters` かつ `total_chapters > 0` を満たす書籍数 | 読了 / 全 N 冊                                                   |

> **【最新の進捗率・集計ロジック（v2.21.13 更新）】**
>
> - **進捗率カードおよび進捗率推移グラフの母数の統一**: 以前は「全タスクに対する累積完了率」でしたが、最新仕様では**「選択した期間（週/月/年）に属するタスクのみ」**を母数とするように統一されました。
> - これにより、期間の開始時点は 0%からスタートし、その期間内で完了・予定消化が進むごとに進捗が上昇する見た目となります（「全期間」トグル時は全タスクが母数となります）。
> - 前期間との比較（先週比／先月比／前年比）も同様に、選択期間の 1 つ前の期間に属するタスクを対象にした完了率を算出して差分を表示します。

### 2.2 画面中部：学習時間グラフ

- **日別学習時間**: 曜日ごと（月〜日）の学習時間を表す棒グラフ（単位：h）。
- **カテゴリ別学習時間**: 技術要素やカテゴリ（TypeScript, Python 等）ごとの学習時間の内訳を表すグラフ。

### 2.3 画面下部：進捗状況

- **ステータス別件数**: 未着手 / 進行中 / 完了 のタスク数を表すグラフ。
- **書籍別進捗率**: 登録書籍ごとの進捗度を％で表す横棒グラフ。
- **カテゴリ別進捗率**: カテゴリごとの進捗度を表すグラフ。
- **進捗率推移**: 選択期間内タスクを対象にした、日別の予定進捗（％）と実績進捗（％）を比較する折れ線グラフ。

## 3. タスク一覧画面

登録された学習タスクを複数のビューに切り替えて管理する画面です。タスクは**「親タスク（グループ）」「子タスク（実作業）」「孫タスク（ステップ）」の 3 階層**構造となっています。

### 3.1 画面共通操作エリア（ヘッダー）

- **「親タスク追加」ボタン**: 右上に配置。親タスク登録ダイアログを開きます。
- **「子タスク表示 / 非表示」トグル**: カンバンおよびテーブルビューで、子タスクを展開表示するか折りたたむかを切り替えます。
- **ビュー切替タブ**: 「カンバン」「テーブル」「カレンダー」「タイムライン」をワンタッチで切り替えます。

> **【UI コンテナの高さ調整仕様（v2.21.11 更新）】**
> カンバン・テーブル・タイムラインの各ビューで下部が見切れないよう、ヘッダー等の高さ実測値からビューコンテナの高さ（`vh`）を動的に自動算出・調整しています。

### 3.2 カンバン表示

- **未着手 / 進行中 / 完了** の 3 カラムでタスクカードをドラッグ＆ドロップでステータス変更・管理します。
- カードの表示項目：「カテゴリタグ」「タスク名」「期日」「予定時間」「実績学習時間」「ステップ達成度（孫タスク消化率）」。

### 3.3 テーブル表示

親タスクをアコーディオン形式で展開し、紐づく子タスクを一覧表示します。

| カラム名       | 種別       | 説明                                                     |
| :------------- | :--------- | :------------------------------------------------------- |
| **タイトル**   | テキスト   | タスク名。親タスクはクリックで子タスク一覧を展開可能     |
| **種別**       | タグ       | 「本」「YouTube」「自己開発」などのタスク種別ラベル      |
| **ステータス** | ステータス | 未着手 / 進行中 / 完了 のステータスラベル                |
| **予定日**     | 日付       | タスクの予定日（締切日）                                 |
| **完了日**     | 日付       | 実際にタスクが完了した日付                               |
| **学習時間**   | 数値       | 実績学習時間 / 予定学習時間（h）                         |
| **ステップ**   | 分数       | 達成したステップ（孫タスク）数 / 全ステップ数（例：2/4） |
| **操作**       | ボタン     | 「編集」ボタンからタスク詳細ダイアログを開く             |

### 3.4 カレンダー表示

- 月間カレンダー形式で表示。各日付に割り当てられたタスクを、期間に応じたバー形式で配置します。
- バー内表示：「カテゴリタグ」「タスク名」「ステップ達成度」。
- **新規追加**: 空きセルをクリックすると、その日付を初期開始予定日に設定した状態で子タスク追加モーダルが開きます。

### 3.5 タイムライン（ガントチャート）表示

- 左側に親タスク名、右側に日付軸（1 日〜30 日等）を配置したガントチャート。
- **追従ヘッダー＆リサイズ対応**: 画面をスクロールしても日付ヘッダーが上部に追従（sticky）。また、バーの端をドラッグ＆ドロップすることで、タスクの期間（開始・終了予定日）を直感的にリサイズ可能です。
- **完了タスク表示 / 非表示トグル**: タイムライン上で完了済みタスクを表示するかを切り替え可能。

## 5. 書籍マスタ画面

学習に使用する書籍を登録・管理し、進捗状況を一元管理する画面です。Google Books API を利用した書籍検索・登録機能を備えています。

### 5.1 画面上部：検索・フィルターエリア

- **書籍を検索...**: キーワードを入力して「検索」ボタンを押すと Google Books API で書籍情報を検索・追加登録可能。
- **登録済みの書籍を絞り込む...**: 登録済み書籍一覧を入力テキストでリアルタイムフィルタリング。

### 5.2 画面中部：書籍カード一覧（縦積み・グリッド表示）

- **表示要素**: 書籍の表紙画像、書籍タイトル、著者名。
- **進捗バー**: 読了した章の割合をプログレスバーと「100% (8/8 章)」のように可視化。

### 5.3 書籍詳細・編集ダイアログ（右サイドパネル形式・v2.21.8/v2.21.14 更新）

書籍カードをクリックした際に、画面右端からスライドインする**「右サイドパネル形式」**のモーダル画面です。ここで各章（子タスク）の完了チェックや詳細メモの記録を行います。

| 項目名                       | 種別                 | 入力ルール / 説明                                                                                                                          |
| :--------------------------- | :------------------- | :----------------------------------------------------------------------------------------------------------------------------------------- |
| **表紙画像**                 | 画像                 | `cover_url` を表示。未設定時は「表紙」のプレースホルダーを表示                                                                             |
| **書籍タイトル**             | ヘッダーテキスト     | 表紙の隣に表示（編集不可。Google Books 登録時の値をそのまま表示）                                                                          |
| **著者名**                   | テキスト             | 著者の氏名を表示・編集可能                                                                                                                 |
| **進捗バー**                 | バー・テキスト       | 「目次」の章タスクのうち、ステータスが「完了」の件数の割合を表示（`進捗 N / M (X%)`）。章が 0 件なら「紐づくタスクがまだありません」と表示 |
| **全章数**                   | 数値                 | 書籍の総ボリュームを半角数字で入力。書籍一覧カードの進捗算出（`completed_count / total_chapters`）に使用                                   |
| **目次（章単位タスク）**     | アコーディオンリスト | 書籍に紐づく子タスク（章）を一覧表示。**各行の「▶ ボタン」で開閉し、章ごとのメモ欄を展開**（詳細は下記仕様を参照）                         |
| **削除 / キャンセル / 保存** | ボタン               | 左下：「削除」 / 右下：「キャンセル」「保存」（`author` と `total_chapters` を保存）                                                       |

> **【章（子タスク）ごとの「理解したこと」「不明点」メモ仕様（v2.21.14 訂正・修正）】**
> 書籍全体のメモではなく、**「目次の各章（子タスク）単位」**で詳細な学習ログを記録する仕様となっています。
>
> 1. **アコーディオン展開**: 「▶」ボタンをクリックすると、その章専用の**「理解したこと」**と**「不明点」**の 2 つのテキストエリアおよび「章のメモを保存」ボタンが表示されます。
> 2. **完了チェックボックス**: 章タイトル横のチェックボックスをクリックすると、ステータスが即時に「完了」⇔「未着手」へ切り替わり、DB へ反映されます（失敗時はアラートで通知）。
> 3. **タスク詳細への遷移**: 章のタイトルテキストをクリックすると、そのタスクの編集モーダル（上記「4.2 子タスク詳細モーダル」）が開きます。
> 4. **メモの保存**: 「章のメモを保存」ボタンを押下すると、その章（`tasks`テーブル）に `understood_memo`（理解したこと）と `unclear_points`（不明点）が保存され、アラートで完了通知されます。

## 6. マンダラチャート画面（目標構造化ツール）

9×9（合計 81 マス）のグリッドを用いて、中心の「達成したい大目標」から周囲の「8 つのサブ目標」、さらにそれらを達成するための「64 のアクションプラン」へと目標を構造化する画面です。

### 6.1 画面構成（中央寄せレイアウト）

- **画面ヘッダー**: チャート選択プルダウン、新規チャート作成ボタン、チャート削除ボタン。
- **グリッドエリア**: 画面中央に美しく配置された 9×9 マスのマンダラチャート表。
- **中央セル（中心目標）**: 目標の核となる大きなテーマを入力。
- **周囲 8 セル（サブテーマ）**: 中心の周囲 8 マスにサブテーマを入力すると、外周 8 ブロックの中央マスにラベルが自動同期されます。

### 6.2 主な機能要素

| 機能名               | 説明                                                                                                       |
| :------------------- | :--------------------------------------------------------------------------------------------------------- |
| **複数チャート管理** | 複数のマンダラチャートを作成・保存し、プルダウンで自由に切り替えて閲覧・編集できます。                     |
| **セル達成トグル**   | 外周の 64 のアクションセルにおいて、完了したアクションはトグル操作で「達成状態」に色付け・マーク可能です。 |
| **進捗バー**         | チャート全体のセル達成度（達成セル数 / 64 マス）をプログレスバーとして画面上部にパーセント表示します。     |
| **子タスク紐づけ**   | アクションセルの内容を、そのままアプリ内の「子タスク」として直接登録・紐づけできる機能を提供します。       |

## 7. リザルト画面（学習振り返り・サマリー）

週次・月次・年次の学習成果や集計データをカード形式で振り返る画面です。期間の境界（週明けや月初など）には自動で振り返りポップアップが表示され、学習の習慣化を強力にサポートします。

### 7.1 画面上部：期間タブ＆自動ポップアップ

- **期間切り替えタブ**: 「週次」「月次」「年次」「全期間」の 4 つのタブで振り返りカードの一覧を切り替えます。
- **自動ポップアップ機能**: 前の期間（先週や先月）の振り返りが未入力の場合、画面遷移時に自動でリザルト入力ポップアップが表示されます。

### 7.2 サマリーカード一覧（過去 ＋ 「現在進行中」期間）

カードリストには「2 週間前」「1 ヶ月前」などの確定済み過去期間のカードに加え、**現在進行中の期間カード**が先頭付近に配置され、いつでもリアルタイムな振り返りや気づきをメモできます。

- **「今週」カード**: 月曜〜日曜の範囲。その週の学習時間・タスク消化数をリアルタイム表示。
- **「今月」カード**: 月初〜月末の範囲。今月の進捗状況を確認・メモ可能。
- **「今年」カード**: 1/1〜12/31 の範囲。年間の目標に対する現在までの成果を管理。

### 7.3 振り返り入力・詳細ポップアップ

カードをクリック、または自動ポップアップで開く振り返り入力ダイアログの表示・入力項目です。

| 項目名                      | 種別           | 説明 / 入力ルール                                                       |
| :-------------------------- | :------------- | :---------------------------------------------------------------------- |
| **期間サマリー指標**        | 表示専用       | 対象期間の「合計学習時間」「完了タスク数」「進捗率」をヘッダーに表示    |
| **目標（Goal）**            | テキストエリア | その期間に設定していた目標を表示・編集                                  |
| **実績（Result）**          | テキストエリア | 期間内の具体的な学習成果や完了事項を記録                                |
| **よかった点（Keep）**      | テキストエリア | うまくいった学習方法や集中できたポイントなどを入力                      |
| **反省点（Problem / Try）** | テキストエリア | 改善すべき課題と、次の期間で試したいアクションを入力                    |
| **備考**                    | テキストエリア | その他自由記述メモ                                                      |
| **気分（Mood）選択**        | アイコン選択   | その期間の達成感やモチベーションを 5 段階の表情アイコン等から選択・保存 |
| **保存 / キャンセル**       | ボタン         | 振り返りデータ（`result_reviews`テーブル）に保存                        |

## 8. 設定画面

アプリケーション内のマスタデータ（タスク種別、カテゴリ等）をカスタマイズ・管理する画面です。

### 8.1 タスク種別管理エリア＆リスト

タスク登録ダイアログの「種別」セレクトボックスに表示される選択肢を自由にカスタマイズします。

| 項目名               | 種別     | 説明                                                                                     |
| :------------------- | :------- | :--------------------------------------------------------------------------------------- |
| **新しい種別名入力** | テキスト | 新しく追加したい種別名（例：動画、記事、自己開発など）を入力                             |
| **「追加」ボタン**   | ボタン   | 入力した名称を下のリスト（DB：`task_types`テーブル）に追加                               |
| **登録済み種別一覧** | リスト   | 登録済み名称の一覧。各行に**「編集（インプレース編集）」**および**「削除」**ボタンを配置 |

### 8.2 タスク言語 / カテゴリマスタ管理

タスク登録の「カテゴリ」で使用する技術要素（言語やフレームワーク名）を管理します。

- **カテゴリ追加フォーム**: 新しい言語・技術名（例：TypeScript, React, Node.js 等）を入力して「追加」。
- **登録済みカテゴリ一覧**: タスク種別同様に、一覧表示から個別に名称の**「編集」**や**「削除」**が可能です。

### 8.3 テーマ・システム設定

- **ライト / ダークモード切替**: サイドナビのトグルボタンに加え、設定画面内でもデフォルトテーマの変更や確認が可能です。
