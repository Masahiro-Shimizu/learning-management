画面定義書：学習記録簿（Learning Log）v2.21.35

本ドキュメントは、学習記録簿アプリケーションの全画面構成・表示項目・入力ルール・画面遷移を定義した仕様書です。要件定義書（learning_management_ver2_21_35_full.md）と対をなし、要件定義書が「何を・なぜ」を扱うのに対し、本書は「画面上のどこに・何が・どう並ぶか」を扱う。

1. システム構成・タスク階層概要

本システムにおけるタスクは以下の 3 階層構造で管理・自動集計される。

[親タスク（グループ／マイルストーン）]
└── [子タスク（実作業／章・節単位）]
└── [孫タスク（ステップ／最小アクション）]
マイルストーン自動算出：親タスクの日付（予定/実績の開始・終了日）は、紐づく子タスクの最小・最大日付から自動計算される（手動編集不可）
実績学習時間・進捗ログ：ステップ詳細保存、またはステップ 0 件の子タスク保存をトリガーとし、前後の差分（増分）のみを study_logs テーブルへ日次記録する 2. 共通レイアウト（サイドナビゲーション）

全画面の左側に常時表示されるメインナビゲーション。

No 項目名 種別 説明／遷移先・機能
1 ロゴ（学習管理） ロゴ トップページ（ダッシュボード）へ遷移
2 ダッシュボード メニュー 「ダッシュボード」画面へ遷移
3 タスク一覧 メニュー 「タスク一覧」画面へ遷移（カンバン/テーブル/カレンダー/タイムライン）
4 書籍マスタ メニュー 「書籍マスタ」画面へ遷移
5 マンダラチャート メニュー 「マンダラチャート」画面へ遷移（9×9 目標構造化）
6 リザルト メニュー 「リザルト」画面へ遷移（週次・月次・年次の振り返り）
7 学習ログ メニュー 「学習ログ」画面へ遷移（study_logs 一覧）
8 ライト／ダーク ボタン 画面テーマ（背景・配色）をトグル切り替え。アイコンは renderThemeToggleLabel()で innerHTML 描画（v2.21.35）
9 設定 ボタン 「設定」画面へ遷移 3. ダッシュボード画面

学習の進捗状況や現在のステータスをグラフや数値で可視化する画面。上部で期間（週次/月次/年次/全期間）の切り替えが可能。期間ラベルはクリックでネイティブの日付ピッカーを起動でき、「<」「>」で前後の期間へ移動する。

3.1 画面上部：サマリーカード
カード名 表示内容 サブテキスト・集計ルール
今週の目標 設定された今期間の定型目標を表示 「🎯 目標を設定」ボタン（Lucide target アイコン、v2.21.35）から編集モーダルを起動
期間の学習時間 選択期間内の合計学習時間（h、小数第 1 位） 前期間比（±N 時間）。全期間時は「全データの通算」表記
進捗率 選択期間に属するステップの完了率（%） 前期間比（±N%）。全期間時は「全データの通算」表記
進行中タスク 選択期間内の進行中タスク数 完了 N / 全 N 件
読了書籍 読了済み冊数（completed_count >= total_chapters） 読了 N / 全 N 冊

数値表示は animateSummaryValue()により、requestAnimationFrame ベースの ease-out cubic イージングでカウントアップ＋フェードインする。

3.2 画面中部・下部：グラフエリア
グラフ名 種別 説明
日別学習時間 棒グラフ（2 系列） 週表示：曜日別、月表示：日別、年表示：月別、全期間：年別。予定時間（薄アンバー）・実績時間（インディゴのグラデーション）
カテゴリ別学習時間 棒グラフ 技術要素・カテゴリごとの学習時間内訳
ステータス別件数 ドーナツ 未着手／進行中／完了のタスク件数分布
書籍別進捗率 横棒グラフ 各登録書籍の進捗度（%）
カテゴリ別進捗率 横棒グラフ カテゴリごとの完了進捗率
進捗率推移 折れ線グラフ 期間内の予定進捗（%）と実績進捗（%）の比較

グラフは upsertChart()により「ゼロデータで生成 →400ms 後に本来データへ差し替え」て表示アニメーションを発生させる。日別学習時間・ステータス別件数・書籍別進捗率・カテゴリ別学習時間・カテゴリ別進捗率の 5 チャートは共通の CHART_ANIMATION（duration: 900, easing: easeOutQuart）、進捗率推移グラフのみ左 → 右に点を描画する専用アニメーションを使用する。

4. タスク一覧画面

登録されたタスクを 4 つのビュー（カンバン・テーブル・カレンダー・タイムライン）で管理する。選択中のビューは localStorage の taskView キーに永続化される。

＋ 親タスク追加 ボタン 親タスク（グループ）作成ダイアログを起動
ビュー切替タブ タブ 「カンバン」「テーブル」「カレンダー」「タイムライン」の表示モード切り替え
子タスク表示/非表示トグル トグル カンバン・テーブルでの下層タスクの展開・折りたたみ
検索・フィルターバー 入力 カテゴリ、ステータス、キーワードによるリアルタイム絞り込み
4.2 各ビューの表示仕様
ビュー名 概要・特徴的な操作
カンバン 「未着手」「進行中」「完了」の 3 カラム構造。ドラッグ＆ドロップでステータス変更可能。カードにはカテゴリタグ、期日、予定/実績時間、ステップ達成度バッジ（n/m）・達成率バーを表示
テーブル 親タスクをアコーディオン形式で展開し、子タスクを一覧表示。タイトル、種別、ステータス、予定日、完了日、学習時間、ステップ数（例: 2/4）を表示

タイムライン（ガント） 左側に親タスク名、右側に日付軸を配置。ヘッダーはスクロール追従（sticky）。バー端のドラッグで期間変更が可能。完了タスクの表示/非表示切り替え、ステータス絞り込みタブ、ステップ表示トグル（Lucide chevron-down）付き 5. タスク登録・編集（モーダル）

5.4 モーダル共通の開閉操作
モーダル右上の ✕ ボタン、またはモーダル外側（オーバーレイ）クリックで閉じる
フッターのボタン構成は「削除」を左端、「キャンセル」「保存」を右側にまとめて配置（親・子タスク共通）
編集中の内容に変更があり保存せずに閉じようとした場合（✕・外側クリック・キャンセルいずれも対象）、「編集の内容は保存されていません。閉じてもよろしいですか？」の確認ダイアログを表示。OK の場合のみ閉じ、キャンセルなら編集状態を維持する
「保存」「削除」成功直後は変更なし状態として扱い、以降の確認ダイアログは表示しない 6. 書籍マスタ画面

Google Books API による検索・自動登録と、登録済み書籍の進捗管理を行う画面。

6.1 画面構成
要素 説明
検索・フィルターエリア Google Books API での新刊検索フォーム、登録済み書籍のキーワード絞り込み
書籍カード一覧（カンバン形式） 「未読／読書中／読了」の 3 ステータスで縦積み表示。表紙画像、タイトル、著者名、進捗バー（N/M 章 (X%)）を表示

ステータス判定（calcBookStatus()）は DB にカラムを追加せず、total_chapters/completed_count および紐づく子タスクの status から表示のたびにフロントエンドで自動算出する。

6.2 書籍詳細・編集パネル（右サイドパネル形式）

書籍カードをクリックすると、画面右端からスライドイン表示される。

総ページ数 数値 total_pages（v2.21.30 追加）
