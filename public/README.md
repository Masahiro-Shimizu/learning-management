## 2. ダッシュボード画面

学習の進捗状況や現在のステータスをグラフや数値で可視化し、一目で把握するための画面です。

### 2.1 画面上部：サマリーカード

- **今週の学習時間**: 今週の合計学習時間。先週比（増減時間）を併記。
- **進捗率**: 全タスクのうち完了したタスクの割合（完了数 / 全体数）を％表示。
- **完了タスク**: 今週完了したタスク件数（完了数 / 全体数）。
- **読了書籍**: 読了した書籍の冊数（読了数 / 全登録冊数）。

### 2.2 画面中部：学習時間グラフ

- **日別学習時間**: 曜日ごと（月〜日）の学習時間を表す棒グラフ（単位：時間）。
- **カテゴリ別学習時間**: 技術要素やカテゴリごとの学習時間を表すグラフ。

### 2.3 画面下部：進捗状況

- **ステータス別件数**: 未着手・進行中・完了のタスク数を表すグラフ。
- **書籍別進捗率**: 登録書籍ごとの進捗度を％で表す横棒グラフ。
- **カテゴリ別進捗率**: カテゴリごとの進捗度を表すグラフ。
- **進捗率推移**: 日別の予定進捗（％）と実績進捗（％）を比較する折れ線グラフ。

## 3. タスク一覧画面

登録された学習タスクを複数のビュー（カンバン、テーブル、カレンダー、タイムライン）に切り替えて管理する画面です。画面右上には「親タスク追加」ボタンが配置されています。

### 3.1 カンバン表示

- **未着手 / 進行中 / 完了** の 3 カラムでタスクカードをドラッグ＆ドロップ等で管理。
- タスクカードには「カテゴリタグ」「タスク名」「期日」「予定時間」「ステップ達成度」を表示。

### 3.2 テーブル表示

親タスクをアコーディオン形式で展開し、含まれる子タスク（章単位など）を一覧表示します。

| カラム名   | 種別       | 説明                                         |
| :--------- | :--------- | :------------------------------------------- |
| タイトル   | テキスト   | タスクの名称。親タスクはクリックで展開可能   |
| 種別       | タグ       | 「本」「YouTube」などのタスク種別ラベル      |
| ステータス | ステータス | 未着手 / 進行中 / 完了 のステータスを表示    |
| 予定日     | 日付       | タスクの予定日（締切日）                     |
| 完了日     | 日付       | 実際にタスクが完了した日付                   |
| 学習時間   | 数値       | 実績学習時間（h）                            |
| ステップ   | 分数       | 達成したステップ数 / 全ステップ数（例：2/4） |
| 操作       | ボタン     | 「編集」ボタンからタスク詳細ダイアログを開く |

### 3.3 カレンダー表示

- 月表示のカレンダー形式。各日付に割り当てられたタスクを期間に応じたバー形式で配置。
- バー内には「カテゴリタグ」「タスク名」「ステップ達成度」を表示。

### 3.4 タイムライン（ガントチャート）表示

- 左側に親タスク名、右側に日付軸（1 日〜30 日）を配置したガントチャート。
- タスクの期間（開始予定日〜終了予定日）をタイムライン上のバーで可視化。

## 4. ダイアログ（モーダル画面）

### 4.1 親タスク登録ダイアログ

「親タスク追加」ボタン押下時に表示される簡易モダールです。

| 項目名                   | 種別           | 入力ルール / 説明            |
| :----------------------- | :------------- | :--------------------------- |
| タイトル                 | テキスト       | 必須入力。親タスクの名称     |
| メモ                     | テキストエリア | 任意入力。タスクの詳細やメモ |
| 削除 / キャンセル / 保存 | ボタン         | 各種アクション実行ボタン     |

### 4.2 タスク詳細・編集ダイアログ

タスクの新規登録、および既存タスクの編集・進捗更新を行うメインダイアログです。

| 項目名                            | 種別             | 入力ルール / 説明                                           |
| :-------------------------------- | :--------------- | :---------------------------------------------------------- |
| タイトル                          | テキスト         | 必須入力。タスクの名称（例：Chapter2 基本的なシンタックス） |
| 種別                              | セレクトボックス | 「設定」画面で管理されているタスク種別から選択              |
| ステータス                        | セレクトボックス | 未着手 / 進行中 / 完了                                      |
| カテゴリ                          | セレクトボックス | 技術要素（TypeScript など）を選択                           |
| 粒度                              | セレクトボックス | タスクの細かさ（章単位など）を選択                          |
| 紐づく書籍                        | セレクトボックス | 「書籍マスタ」に登録されている書籍タイトルから選択          |
| 開始予定日 / 終了予定日           | 日付選択         | タスクの予定期間を設定（YYYY/MM/DD）                        |
| 開始日（実績） / 終了日（実績）   | 日付選択         | 実際の着手日および完了日を入力                              |
| 予定学習時間（h） / 学習時間（h） | 数値             | 予定時間と実績時間を半角数字で入力                          |
| メモ                              | テキストエリア   | 自由記述用の詳細メモ欄                                      |
| **ステップ**                      | エリア           | 各章の中の細かいタスク（005 環境構築など）を管理するエリア  |
| └ チェックボックス                | チェック         | 完了したステップにチェック。全体の進捗率に連動              |
| └ 新しいステップ                  | テキスト         | 追加したいステップ名を入力するフォーム                      |
| └ 「追加」ボタン                  | ボタン           | 入力したステップをリストに追加                              |
| └ 「×」ボタン                     | ボタン           | 各ステップの右側に配置。クリックでステップを削除            |
| **アクションボタン**              | ボタン           | 左下：「削除」 / 右下：「キャンセル」「保存」               |

## 5. 書籍マスタ画面

学習に使用する書籍を登録・管理し、進捗状況を一元管理する画面です。

### 5.1 画面上部：検索・フィルターエリア

- **書籍を検索...**: キーワードを入力して「検索」ボタンで書籍を絞り込み。
- **登録済みの書籍を絞り込む...**: 入力されたテキストに基づくリアルタイムフィルタリング。

### 5.2 画面中部：書籍カード一覧

登録された書籍がグリッド（カード形式）で一覧表示されます。

- **表示要素**: 書籍の表紙画像、書籍タイトル、著者名。
- **進捗バー**: 読了した章の割合をプログレスバーと「100% (8/8 章)」のようなテキストで可視化。

### 5.3 書籍詳細・編集ダイアログ

書籍カードをクリックした際に表示される、書籍情報の編集用モーダル画面です。

| 項目名                   | 種別             | 入力ルール / 説明                             |
| :----------------------- | :--------------- | :-------------------------------------------- |
| 書籍タイトル             | ヘッダーテキスト | ダイアログの最上部に表示                      |
| 著者名                   | テキスト         | 著者の氏名を表示・編集                        |
| 全章数                   | 数値             | 書籍のボリューム（総章数）を半角数字で入力    |
| メモ                     | テキストエリア   | 書籍に関する備考やメモ                        |
| 削除 / キャンセル / 保存 | ボタン           | 左下：「削除」 / 右下：「キャンセル」「保存」 |

## 6. 設定画面

アプリケーション内のマスタデータ（各種プルダウンの選択肢など）をカスタマイズする管理画面です。

### 6.1 タスク種別管理エリア

タスク登録ダイアログの「種別」セレクトボックスに表示されるマスタデータを動的に追加します。

| 項目名         | 種別     | 入力ルール / 説明                                      |
| :------------- | :------- | :----------------------------------------------------- |
| 新しい種別名   | テキスト | 新しく追加したい種別の名称を入力（例：動画、記事など） |
| 「追加」ボタン | ボタン   | 入力した種別名を下のマスタリストに追加                 |

### 6.2 タスク種別リスト（登録済み一覧）

現在登録されている種別が縦並びのリストで一覧表示されます（例：本、YouTube、自己開発、CyTech）。

| 各行の構成要素 | 種別     | 説明                                                       |
| :------------- | :------- | :--------------------------------------------------------- |
| 種別名         | テキスト | 登録されている名称                                         |
| 「編集」ボタン | ボタン   | 対象の種別名を入力可能状態（インプレース編集等）に切り替え |
| 「削除」ボタン | ボタン   | 対象の種別をマスタから削除                                 |
